# 긴급 옷 코디

바쁜 아침, 약속 직전, 갑작스러운 외출 상황에서 "지금 당장 입을 옷"을 빠르게 추천해주는 코디 앱 기획서입니다.

## 1) 문제 정의

- 많은 사용자가 아침에 5~15분을 옷 고르기에 사용하며, 지각/스트레스가 발생함
- 날씨, 일정(회사/데이트/면접), 체형, 보유 의류를 동시에 고려하기 어려움
- 옷은 많은데 "입을 옷이 없다"는 선택 피로가 반복됨

## 2) 핵심 기능

### 1. 30초 긴급 코디(핵심 기능)
- 상황 + 날씨 기준으로 30초 내 코디 1세트 추천
- 세탁/부적합 아이템 제외한 대체 코디 2~3개 제공

### 2. 내 옷장 등록
- 가진 옷을 종류별로 저장하고 표시 정보(색상/소재/계절) 관리

### 3. 상황별 코디 프리셋
- 출근/편한 옷/격식 있는 옷처럼 자주 쓰는 스타일을 저장해 빠르게 불러오기

### 4. 코디 기록/재사용
- 입었던 코디 저장, 다시 쓰기, 만족도 기준 추천 조정

## 3) 기대 효과

- 준비 시간 단축: 아침 코디 시간을 줄이는 데 도움
- 지각/스트레스 감소: 빠른 의사결정으로 아침 루틴 안정화
- 옷 활용도 증가: 안 입던 아이템의 재발견
- 만족도 향상: 상황과 날씨에 맞는 코디 제안

## 4) 페르소나

### 페르소나 1: 28세 직장인 "민지"
- 아침 출근 준비가 늘 촉박함
- 회의 있는 날은 깔끔한 복장이 필요함
- 원하는 가치: 빠르고 무난하면서도 깔끔한 코디

### 페르소나 2: 21세 대학생 "준호"
- 수업/동아리/약속으로 하루 일정이 자주 바뀜
- 매일 다른 코디를 원하지만 고민 시간은 짧게 쓰고 싶음
- 원하는 가치: 상황별로 센스 있는 코디를 빠르게 확인

## 5) 핵심 화면 구성

### 화면 1. 처음 설정/프로필
- 상단:
	- 좌측: 뒤로가기 아이콘
	- 중앙: "프로필 설정" 제목
	- 우측: "건너뛰기" 텍스트 버튼
	- 하단: 진행 단계 표시(1/3, 2/3, 3/3)
- 중단:
	- 1순위 입력: 체형(선택 목록)
	- 2순위 입력: 선호 스타일(여러 개 선택 버튼)
	- 3순위 입력: 자주 가는 장소(한 개 선택)
	- 4순위 입력: 복장 규정(자유 입력)
- 하단:
	- 좌측: "이전" 버튼
	- 우측: "다음" 또는 "완료" 버튼

### 화면 2. 홈(긴급 코디 시작)
- 상단:
	- 1행: 인사 문구 + 사용자 이름
	- 2행: 오늘 날짜
	- 3행: 날씨 묶음(기온, 체감온도, 비 올 확률)
- 중단:
	- 중앙 고정: "30초 코디 시작" 큰 시작 버튼
	- 시작 버튼 아래: 상황 선택 버튼(출근/학교/약속/운동/기타)
	- 상황 버튼 아래: 최근 코디 바로가기 2개
- 하단:
	- 아래 메뉴: 홈 | 내 옷장 | 저장 코디 | 설정

### 화면 3. 긴급 코디 결과
- 상단:
	- 좌측: 뒤로가기
	- 중앙: "추천 결과"
	- 상단 요약: 선택 상황 + 날씨(예: 출근 / 22도 / 비 가능성 20%)
- 중단:
	- 추천 옷 묶음 1개(상의/하의/아우터/신발 순서 고정)
	- 각 아이템 우측: "교체" 버튼
	- 옷 묶음 아래: 추천 이유(날씨/상황 기준 1줄)
- 하단:
	- 1행: "다른 조합 보기" 보조 버튼
	- 2행: 좌측 "저장", 우측 "오늘 코디 확정" 버튼

### 화면 4. 내 옷장

- 상단:
	- 상단 제목: "내 옷장"
	- 검색창: 옷 이름/표시 정보 검색
	- 종류 탭: 상의 | 하의 | 아우터 | 신발
- 중단:
	- 옷 목록(작은 사진, 이름, 색상/소재/계절 표시)
	- 옷 목록 우측 상단: 사용 빈도 표시(높음/보통/낮음)
	- 길게 누르기: 여러 개 선택 모드 시작
- 하단:
	- 오른쪽 아래 고정 버튼: "+ 옷 추가"
	- 좌하단 보조 버튼: "일괄 편집"

### 화면 5. 저장 코디

- 상단:
	- 제목: "저장 코디"
	- 조건 선택: 즐겨찾기 | 최근 | 상황별
	- 정렬: 최신순 | 많이 사용순
- 중단:
	- 코디 목록(작은 사진, 코디 이름, 저장일)
	- 각 코디 아래: "다시 입기" 버튼
	- 각 코디 더보기 메뉴: 이름 변경/삭제
- 하단:
	- 좌측: "편집" 버튼
	- 우측: "선택 코디 적용" 버튼

## 6) 1달 개발 일정

### 1주차: 기획/설계
- 사용자 이동 흐름 정리
- 데이터 구조 설계(옷장, 태그, 코디 결과)
- 화면 뼈대 초안 제작

### 2주차: 핵심 기능 개발
- 회원/프로필/처음 설정 기능 만들기
- 내 옷장 등록 기능 구현
- 날씨 연결 및 30초 긴급 코디 추천 규칙 1차 완성

### 3주차: 고도화
- 코디 대체안 추천, 자주 쓰는 스타일 저장
- 코디 기록/재사용 기능 구현
- 화면 사용성 개선 및 속도 개선

### 4주차: 테스트/출시 준비
- 전체 기능 점검, 오류 수정
- 실제 사용자 의견 반영
- 앱스토어/플레이스토어 출시 준비

## 7) 이 앱을 써야 하는 이유

- 아침 출발 직전, 생각보다 "결정"이 가장 큰 시간 낭비이기 때문
- 긴급 옷 코디는 이 결정을 빠르게 돕는 실사용 중심 앱이기 때문
- 단순 패션 앱이 아니라, 바쁜 일상의 "시간 절약 도구"이기 때문

## 8) 한 줄 가치 제안

"긴급 옷 코디"는 바쁜 아침 오늘의 옷 고민을 빠르게 정리하고, 지각과 스트레스를 줄이는 데 도움을 주는 코디 앱입니다.
